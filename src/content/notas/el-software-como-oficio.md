## Hacer bien un trabajo

El desarrollo de software también puede pensarse como una práctica: observar, decidir, construir, mantener y aprender. No solo elegir herramientas.

Una versión real de esta nota podría partir de una situación concreta: una decisión técnica aparentemente pequeña que cambió la facilidad de mantenimiento de un proyecto.
